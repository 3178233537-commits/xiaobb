# 缺陷记录 — 老年人预问诊综合评估系统

记录测试阶段发现并已修复的缺陷，均已在 `tests/medical-flow.test.js` 增加回归断言。

## BUG-001 NRS2002 终筛得分把初筛分重复计入

- 现象：75 岁老人初筛第 3 题为"是"，终筛营养受损 1 分、疾病严重 0 分，报告显示 2 分（应为 1+年龄 1=2），但当只答终筛题时结果仍偏高。
- 原因：`judge` 使用 `tot`（该量表全部已答条目分值之和），把初筛 4 道 0/1 题的分数也累加进终筛总分。
- 修复：改为只累加终筛条目 `(n5||0)+(n6||0)`，再叠加年龄≥70 的 1 分。位置 `medical/js/data.js` 的 `nrs2002.judge`。
- 回归：断言"终筛 1 分 + 年龄 1 分 = 2 分"与"终筛≥3 判为存在营养风险"。

## BUG-002 NRS2002 条件条目在作答后整页重渲染，导致后续点击落空

- 现象：选择初筛题后终筛条目应动态出现，但页面重渲染使已有 DOM 引用失效，自动化连续点击时命中游离节点，流程卡在量表页。
- 原因：条件条目用 `return ''` 不渲染，作答后调用整页 `vDeep()` 重建 DOM。
- 修复：条件条目始终渲染，用 `style="display:none"` 控制显隐；作答后就地切换 `display`，不再重建页面。位置 `medical/js/app.js` 的 `itemHtml` 与 `dans` 分支。
- 回归：完成 NRS2002 全量表后能正常进入下一量表。

## BUG-003 居家环境量表（是/否型）渲染崩溃

- 现象：进入 B.9 居家环境 14 项量表时抛错，页面空白。
- 原因：该量表条目未定义 `options` 数组，渲染分支直接访问 `it.options.map`。
- 修复：新增"是/否"分支，`sc.yesNo || !it.options` 时渲染固定两个选项（是=1、否=0）。位置 `medical/js/app.js` 的 `itemHtml`。
- 回归：14 项全"是"得 14 分判"安全"；2 项"否"判"轻度隐患（2项）"并列出隐患清单。

## BUG-004 重置按钮首次点击空指针

- 现象：首次点击"重新开始"时控制台报 `Cannot set properties of null`。
- 原因：二次确认逻辑直接写 `btn.querySelector('.sub').textContent`，而按钮在续答态与初始态结构不同。
- 修复：取到元素后再赋值，取不到则跳过。位置 `medical/js/app.js` 的 `reset2` 分支。
- 回归：断言首次点击仅进入待确认态（`armed=1`），再次点击才清空草稿。
