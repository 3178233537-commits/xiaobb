## 三、技术栈偏差与决策

### 偏差事实

参考仓库是住院护理评估智能体平台的 monorepo（FastAPI + LangGraph + Redis + PostgreSQL / Next.js + Tailwind），本项目是门诊预问诊前端原型，功能为量表配置、条件触发、计分、报告生成与打印，全部可在浏览器内完成。

### 不迁移的理由

1. 本系统无多轮 AI 对话、无流式推理、无长事务，引入 FastAPI/Redis/PG 不产生功能收益，只增加部署与运维成本。
2. 现有 `data.js` 已把量表、选项、分值、阈值、宣教建议全部配置化，后续若需服务端下发配置，可按同一数据结构平移，迁移成本可控。
3. 报告目前依赖浏览器 `localStorage`，属于演示级存储；若转生产，必须补后端持久化与权限（这属于新增需求，不在本次范围）。
