# 任务二 — 技术栈选择与数据库设计

> 依据：参考项目 `medical-evaluate-main`（FastAPI + Next.js monorepo + 30+ 表数据库设计）

## 一、技术栈决策（已确认方案 A）

### 方案比选

| 方案 | 决策 | 理由 |
|---|---|---|
| A. 维持纯前端 + 设计数据库文档 | ✅ 选中 | 已有 76/76 测试过；数据库文档作为后续立项依据；不引入部署复杂度 |
| B. 加 FastAPI 后端 + 保留前端 | ❌ 放弃 | 本机缺 PostgreSQL/Redis 无法联调；前端改 fetch 重写状态持久化层风险高 |
| C. 完整迁移 monorepo | ❌ 放弃 | 参考项目的 AI Agent / Celery / AI 对话是住院场景需求，门诊预问诊用不上 |

### 偏差记录

- 现有 `docs/plan/预问诊系统-开发计划.md` 步骤 5.8 标记"技术栈迁移 FastAPI + Next.js"，经方案 A 确认后保持原状（不勾选），后续若启动生产化立项再单独评估。
