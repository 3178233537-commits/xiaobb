# 老年人预问诊综合评估系统 — 开发计划

> 依据：参考项目 `AGENTS.md`（开发规范 / 计划文档规范）
> 需求来源：`medical/_docx_原文.txt`（《老年人预问诊综合评估系统项目需求与功能规划方案》，量表依据 WS/T 888—2026）

## 一、项目目标

面向门诊预问诊场景，在老人正式就诊前完成 24 题筛查与按需深度评估，自动算分、判定风险并生成《老年综合评估报告》，操作不超过三步，适配老年人使用习惯。
