# 星选 Nova 商城 — UI 设计文档

> 版本：v1.0 ｜ 日期：2026-10-17
> 适用范围：`index.html` / `css/style.css` / `js/*.js`
> 设计基准：Apple 官网设计语言（极简、大留白、清晰字阶、顺滑动效）

---

## 1. 设计原则

| 原则 | 落地方式 |
|---|---|
| 极简主义 | 单色系界面 + 单一品牌蓝强调色；无装饰性边框与渐变背景 |
| 内容优先 | 最大内容宽度 1200px，大留白（Section 垂直间距 96px） |
| 字阶清晰 | 84px Hero → 48px 标题 → 17px 正文 → 13px 辅助，共 5 级 |
| 一致圆角 | 胶囊 980px / 卡片 18px / 弹层 28px / 输入框 12px 四档 |
| 顺滑动效 | 全部过渡统一 `cubic-bezier(0.4,0,0.2,1)`，时长 0.2–0.5s |
| 性能友好 | 仅 transform/opacity 动画（GPU 合成层），系统字体栈零加载 |

## 2. 色彩规范

### 2.1 核心色板（CSS 变量，定义于 `style.css :root`）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--c-bg` | `#FFFFFF` | 页面主背景 |
| `--c-bg-2` | `#F5F5F7` | 次级背景（服务区/媒体占位/页脚），Apple 标志性浅灰 |
| `--c-text` | `#1D1D1F` | 主文字（近黑，非纯黑，降低视觉疲劳） |
| `--c-text-2` | `#6E6E73` | 次级文字（副标题、说明） |
| `--c-text-3` | `#86868B` | 三级文字（辅助信息、占位符、规格键名） |
| `--c-blue` | `#0071E3` | 品牌主色：主按钮、链接、角标、进度条 |
| `--c-blue-h` | `#0077ED` | 主色 hover 态（亮度 +3%） |
| `--c-green` | `#30D158` | 成功态：Toast 图标、开关开启、支付成功、密码强度-强 |
| `--c-orange` | `#FF9F0A` | 强调点缀：Hero eyebrow、密码强度-中 |
| `--c-red` | `#E30000` | 错误态：表单错误、错误边框、密码强度-弱 |
| `--c-border` | `rgba(0,0,0,0.10)` | 常规描边（输入框、步进器） |
| `--c-border-soft` | `rgba(0,0,0,0.06)` | 弱分隔线（卡片边、列表行） |

### 2.2 功能色用法规则

- **评分星**：激活 `#F5A623`，未激活 `#D6D6DB`
- **降价标签**：文字 `#B25000` + 底 `#FFF3E6`
- **推荐原因标签**：文字 `--c-blue` + 底 `rgba(0,113,227,0.09)`
- **微光占位（骨架）**：`#ECECF0 → #F7F7F9` 渐变扫光动画
- **Toast**：底色 `rgba(29,29,31,0.86)` + `backdrop-filter: blur(14px)`
- **渐变标题**：`linear-gradient(94deg, #0090F7, #6F5BFF, #B85CFF)`，仅用于 Hero 与头像
- **禁止**：正文/按钮不使用纯黑 `#000`；错误红不用于大面积填充

### 2.3 毛玻璃材质

导航栏与浮层使用 Apple 标志性毛玻璃：

```css
background: rgba(255,255,255,0.72);
backdrop-filter: saturate(180%) blur(20px);
```

## 3. 字体规范

### 3.1 字体栈（零网络加载，全平台原生渲染）

```css
--font: "SF Pro Display", "SF Pro Text", -apple-system, BlinkMacSystemFont,
  "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

全局开启 `-webkit-font-smoothing: antialiased`，字距 `letter-spacing: -0.012em`（大字 -0.02em ~ -0.025em，越大的字收得越紧）。

### 3.2 字阶系统

| 层级 | 字号 | 字重 | 应用 |
|---|---|---|---|
| Display | `clamp(42px, 7vw, 84px)` | 700 | Hero 主标题 |
| H2 | `clamp(30px, 4vw, 48px)` | 700 | Section 标题 |
| H3/价格大 | 22–30px | 700 | 弹窗标题、详情价格、合计金额 |
| 正文 | 17px | 400 | 全局基准（`body`） |
| 强调正文 | 15–16px | 500/600 | 商品名、按钮、列表项 |
| 辅助 | 13–14px | 400/500 | 副文案、标签、表单标签 |
| 微型 | 11–12.5px | 600 | 徽章、角标、原因标签（常配合大写 + 0.04em 字距） |

## 5. 阴影规范

| 变量 | 值 | 应用 |
|---|---|---|
| `--shadow-card` | `0 4px 24px rgba(0,0,0,.05)` | 静态卡片、服务图标 |
| `--shadow-hover` | `0 16px 48px rgba(0,0,0,.12)` | 卡片 hover、推荐卡 hover |
| `--shadow-sheet` | `0 24px 80px rgba(0,0,0,.22)` | 详情/登录/结算弹层 |
| 抽屉 | `-20px 0 60px rgba(0,0,0,.14)` | 购物袋抽屉（左侧投影） |

规则：阴影只随「层级」增长，不用彩色阴影（品牌蓝辉光仅头像 hover 一处例外）。

## 6. 组件样式规范

### 6.1 按钮体系

| 变体 | 规格 | 状态 |
|---|---|---|
| `.btn-primary` | 高 44px / 圆角 980 / 蓝底白字 | hover 换 `#0077ED`；active `scale(0.97)`；disabled 透明度 0.55 |
| `.btn-dark` | 同上，深灰底 `#1D1D1F` | 用于「立即购买」等次级强操作 |
| `.btn-ghost` | 透明底 + 1px 蓝色内描边 | hover 底 `rgba(0,113,227,.06)` |
| `.btn-pill-sm` | 高 34px / 13px 字 | 卡片内「加入购物袋」 |
| `.btn-nav` | 高 30px / 13px 字 | 导航栏「登录」 |
| `.icon-btn` | 36px 圆形透明 | hover 灰底、active `scale(0.92)` |
| `.quick-add` / `.mini-add` | 38px / 28px 圆形 | 卡片悬浮快捷加购（毛玻璃白底） |

所有按钮统一：`:active { transform: scale(.97) }` 提供按压反馈；加载态内嵌 `.spinner`（15px 旋转圆环）。

### 6.2 表单组件

- **输入框**：高 48px、12px 圆角、1px `#D2D2D7` 描边；focus 时描边变蓝 + `box-shadow: 0 0 0 3.5px rgba(0,113,227,.16)` 光环；错误态描边红 + 红色光环。
- **错误文案**：字段下方 12px 红字，`min-height: 17px` 占位防抖动。
- **密码眼睛**：输入框右侧 34px 圆形按钮切换明文/密文。
- **强度条**：3 段 4px 高胶囊，弱红 / 中橙 / 强绿，`data-s` 属性驱动。
- **iOS 开关**：42×25px 胶囊轨道 + 21px 白球，开启变绿，球体带投影平移。
- **步进器**：胶囊描边容器内嵌「− 数量 ＋」，禁用态灰字，小号变体用于购物车行。

### 6.3 导航栏

- 高 52px、sticky 置顶、毛玻璃白底、底部 0.06 透明分隔线
- 结构：Logo（26px 圆角图标 + 17px 字标）/ 链接（13.5px、75% 黑）/ 操作区（搜索、购物袋、头像或登录钮、汉堡）
- 购物袋角标：16px 蓝色圆点，加购时播放 `bump` 缩放脉冲
- ≤820px：链接折叠为全宽下拉面板（毛玻璃），汉堡 ↔ 关闭图标切换

### 6.4 商品卡片

- 白底 + 18px 圆角 + 0.06 描边；hover：上浮 7px + 大阴影 + 描边透明化，图片 `scale(1.06)` 慢速放大（0.7s）
- 媒体区：1:1 灰底，图片淡入（0.5s），加载前微光扫过
- 徽章：左上胶囊（新品蓝 / 热卖黑）；快捷加购：右下 38px 毛玻璃圆钮，hover 卡片时上浮淡入
- 信息区：20px 商品名 → 13px 双行截断卖点 → 19px 价格 + 划线价 → 分隔线 → 「进一步了解 / 加入购物袋」

### 6.5 浮层与弹窗

| 组件 | 形态 | 动效 |
|---|---|---|
| 搜索浮层 | 全屏白底 88% 透明 + 模糊，顶部大输入框 | 面板自上方 14px 滑入 |
| 购物袋抽屉 | 右侧 420px（移动全宽） | `translateX(102%→0)` 弹簧曲线 0.36s，遮罩淡入 |
| 商品详情 | 居中 960px、28px 圆角 Sheet | `scale(.96)+translateY(10px)→1` 0.32s |
| OAuth / 结算 | 居中 380/420px 小 Sheet | 同上 |
| Toast | 底部居中胶囊黑底 | `translateY(14px)→0` 淡入，2.4s 自动消失 |

所有弹层：遮罩 `rgba(22,22,23,.42)` + 10px 模糊；Esc 键逐层关闭；打开时 `body.no-scroll` 锁定滚动。

### 6.6 特色组件

- **免运费进度条**：5px 圆角轨道 + 蓝色渐变填充，达标文案切换
- **飞入动画**：72px 圆角商品图幽灵元素，`Web Animations API` 三段式抛物线（先上抬再落入购物袋图标）
- **支付成功**：SVG 圆环 + 对勾 `stroke-dashoffset` 描边动画（0.7s + 0.45s 延迟接力）
- **图片放大镜**：详情图 hover 时 `scale(1.75)`，`transform-origin` 跟随鼠标坐标实时计算

## 7. 动效规范

### 7.1 曲线与时长

| 用途 | 曲线 | 时长 |
|---|---|---|
| 标准过渡 | `cubic-bezier(0.4,0,0.2,1)` | 0.2–0.3s |
| 卡片/抽屉位移 | `cubic-bezier(0.32,0.72,0.35,1)`（弹簧感） | 0.36–0.5s |
| 图片淡入 | ease 系 | 0.5–0.8s |
| 滚动渐入 | rise（26px 上移 + 淡入） | 0.65s，卡片间 50ms 阶梯延迟 |

### 7.2 规则

1. 只动画 `transform` / `opacity`（不触发重排）
2. hover 位移上限 7px，缩放上限 1.06，避免浮夸
3. `@media (hover:none)` 下禁用悬停位移（触屏设备）
4. `@media (prefers-reduced-motion:reduce)` 下全部动画降为 0.01ms
5. 图片全部声明 `width/height` + `loading="lazy"`，零布局偏移（CLS≈0）

## 8. 响应式规范

| 断点 | 变化 |
|---|---|
| ≥1101px | 商品 4 列 / 推荐 4 列 |
| ≤1100px | 商品 3 列 / 推荐 2 列 |
| ≤820px | 汉堡菜单、服务条纵排、商品 2 列、详情弹窗改单列、登录卡收窄 |
| ≤520px | 商品/推荐单列、Hero CTA 全宽、抽屉全宽、详情 Sheet 全屏贴边、快捷加购常显 |

辅助措施：`body { overflow-x: clip }` 防意外横向滚动；触摸设备快捷加购按钮常显（无 hover）。

---

## 9. 可访问性

- 所有图标按钮带 `aria-label`；弹层带 `role="dialog" aria-modal="true"`
- 汉堡/头像菜单同步 `aria-expanded`；Toast 容器 `aria-live="polite"`
- `:focus-visible` 蓝色 2px 外描边；表单错误与字段 `label` 关联
- 色彩对比：主文字/辅助文字均满足 WCAG AA（≥4.5:1）

## 10. 交互逻辑总览

```
┌─ 路由层（app.js）──────────────────────────────
│  #/home ⇄ #/login   已登录访问 /login 自动重定向
│  Esc 全局逐层关闭：OAuth → 结算 → 详情 → 搜索 → 抽屉
│
├─ 认证层（auth.js）─────────────────────────────
│  登录/注册成功 → App.onAuthSuccess(更新头像)
│                → 若有 pendingCheckout → 自动弹结算
│  第三方登录    → 模拟 OAuth 授权卡 → 同上
│
├─ 购物层（shop.js）─────────────────────────────
│  加购 → 飞入动画 + 角标脉冲 + Toast + 运费进度重算
│  浏览详情 → 写入 nova_history → 驱动推荐权重
│  结算 → 未登录：Toast + 跳登录 + 记录 pendingCheckout
│        已登录：确认订单 → 模拟支付 → 成功动画 → 清空购物车
│
└─ 持久化（localStorage）────────────────────────
   nova_users / nova_session / nova_cart
   nova_history / nova_search_history / nova_lock
```
